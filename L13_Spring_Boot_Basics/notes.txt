Object creation:
1. Developer themselves can create an object of a particular class and maintain it's lifecycle
2. Spring boot creates an object for you, puts in the memory and fetches the object whenever needed,
   basically spring boot manages the entire lifecycle of the object.


Two pillars of spring boot
1. Inversion of control - the process of creating objects on application startup by spring boot is known as inversion of control

How to communicate to spring boot about creating an object during application startup
1. @Component annotation either directly or indirectly on top of a class
