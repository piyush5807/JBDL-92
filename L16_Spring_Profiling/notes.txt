Profiling...


If the user has defined multiple active profiles, it tries to do the union of all the properties mentioned in all the active profiles
and if there's a property which is present in multiple profiles, then SB uses the last active profile's property value


---------------------------

spring.config.name --> Used to change the name of configuration files
